# TruthLens - Hackathon Submission

Hackathon ID: AZIS-D43PJF

## Track
Track 2: Real-World AI Products (TruthLens)

## Tech Stack
- HTML5, Tailwind CSS, JavaScript (Vanilla)

## Features Implemented
1. Submit a claim (with platform & category selection)
2. Automated Risk Flags (detects ALL CAPS, Sensational words, etc.)
3. Review Workflow (update status and add reviewer notes)
4. Public Feed (with category and status filters)
5. Detail View & Review Modal
